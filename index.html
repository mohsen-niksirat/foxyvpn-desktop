چطور کار می‌کند؟

FoxyVPN Desktop با اکانت رایگان فایرفاکس وارد می‌شود، از سرویس Guardian موزیلا یک proxy pass می‌گیرد و یک تونل رمزنگاری‌شده HTTP/2 به شبکه لبه Fastly برقرار می‌کند — همان زیرساختی که خود Firefox VPN از آن استفاده می‌کند. بعد یک پروکسی SOCKS5/HTTP محلی سرو می‌کند و ترافیک سیستم را از همان تونل رد می‌کند.

آموزش فعالسازی — ۳ دقیقه

۱
اکانت Firefox بساز

به accounts.firefox.com برو و با ایمیل واقعی خودت یک اکانت رایگان بساز. (بدون نیاز به کارت بانکی یا اشتراک)

۲
برنامه را دانلود و اجرا کن

از صفحه Releases فایل foxyvpn-desktop-app-win64.zip را بگیر، بازش کن و روی foxyvpn-desktop-app.exe دابل‌کلیک بزن. پنجره اپ باز می‌شود — نیازی به نصب نیست.

۳
وارد شو

ایمیل و رمز اکانت فایرفاکست را وارد کن و «ورود» را بزن. فقط همین یک بار — از دفعه بعد برنامه خودش اتومات وصل می‌شود.

۴
وصل شو

روی دکمه دایره‌ای بزرگ بزن. حلقه زرد می‌چرخد («در حال اتصال…») و وقتی دایره سبز شد، وصل هستی ✅ — کشور دلخواهت را هم از منوی بالا انتخاب کن.

DISCONNECT
وصل — برای قطع لمس کنید
۵
لذت ببر

مرورگر و همه برنامه‌ها حالا از تونل رد می‌شوند. امتحان کن: whatismyipaddress.com — باید IP کشور انتخابی‌ات را ببینی. 🚀

حالت TUN (وی‌پی‌ان کل سیستم)

اگر می‌خواهی همه ترافیک سیستم (حتی برنامه‌هایی که تنظیم پروکسی ندارند) از تونل برود:

  • برنامه را با Run as Administrator اجرا کن
  • دکمه «TUN Mode» را بزن — یک آداپتور مجازی ساخته می‌شود و کل ترافیک رد می‌شود
  • برای برگشت، دوباره همان دکمه را بزن یا Disconnect کن

⚠️ هشدار: حالت TUN کل ترافیک را رد می‌کند؛ اگر از RDP یا شبکه محلی استفاده می‌کنی، اول اتصالت را چک کن.

عیب‌یابی

  • پنجره سفید باز شد؟ — WebView2 Runtime را نصب کن (ویندوزهای جدید معمولاً دارند)
  • اتصال وصل است ولی سایت باز نمی‌شود؟ — یک بار Disconnect و Connect بزن؛ فایل foxyvpn-debug.log کنار برنامه را چک کن
  • پروکسی سیستم روشن ماند؟ — بعد از Quit باید خاموش شود؛ اگر ماند: Settings ← Network ← Proxy را دستی off کن
  • پورت اشغال است؟ — از تب تنظیمات، پورت SOCKS5/HTTP را عوض کن
  • خطای ۴۲۹ یا سهمیه؟ — سهمیه ۵۰ گیگی ماهانه تمام شده؛ ماه بعد دوباره پر می‌شود

محدودیت‌ها و مسئولیت

  • این پروژه غیررسمی است و به Mozilla وابستگی ندارد
  • فقط برای استفاده شخصی و آموزشی — برای دور زدن پرداخت یا سوءاستفاده از سرویس Mozilla نیست
  • با یک اکانت واقعی خودت استفاده کن؛ ساخت اکانت‌های متعدد نقض قوانین سرویس است
  • پروتکل‌های استفاده‌شده از ریپوهای متن‌باز FoxyVPN و firefox-vpn-client استخراج شده‌اند
