## Firefox VPN 是什么？

**Firefox VPN** 是一款免费、开源的 VPN，使用 Firefox 账户（Firefox Account）登录。它通过 Mozilla 的服务器，基于 **Fastly** 的基础设施，以安全的 **HTTP/2 和 HTTP/3** 隧道传输你的网络流量。

每个 Firefox 账户每月有 **50 GB 免费流量**，**多账户**功能让流量成倍增加：一个账户用完后，下一个会**自动**接上。

支持 **Android、Windows、macOS 和 Linux**；完全免费，没有广告。

**该下载哪个文件？**

- **Android：** 不确定的话，选 **Universal**，所有手机都能安装。**ARMv8** 适用于大多数现代手机，体积更小。
- **Windows：** **Setup** 是普通安装程序；**Portable** 无需安装，可在任意文件夹运行。
- **Linux：** **App** 用于 Linux 桌面（有图形界面）；**Core** 用于服务器（无图形界面，带网页面板）。

### 🌐 网页面板

在 Linux 服务器上，Firefox VPN 提供一个**网页面板**，可在任何浏览器中打开，拥有应用的全部功能：管理账户和流量、选择服务器并测试延迟、连接测试、实时日志以及所有设置。

<p align="center"><img src="../screenshots/web.webp" width="720" alt="Web panel"></p>

- **面板地址：** `http://SERVER-IP:10820/app/`，需要用户名和密码。安装结束时会显示确切地址。
- **代理：** 端口 `10810` 上的 SOCKS5 和 HTTP，使用单独的用户名和密码。

### ⌨️ 在终端中管理

在服务器上运行 `sudo firefox-vpn`，即可打开管理菜单：

```text
$ sudo firefox-vpn

  Firefox VPN
  ────────────────────────────────────────────────────────────────────────────
   1) Status                                   firefox-vpn status
   2) Start                                    firefox-vpn start
   3) Stop                                     firefox-vpn stop
   4) Restart                                  firefox-vpn restart
   5) Start with the server                    firefox-vpn enable
   6) Do not start with the server             firefox-vpn disable
   7) Show the log                             firefox-vpn logs
   8) Add a Firefox Account                    firefox-vpn add-account
   9) List the accounts and their quota        firefox-vpn list-accounts
  10) Set the panel's username and password    firefox-vpn set-dashboard-login
   0) Exit
  ────────────────────────────────────────────────────────────────────────────
  Enter a number [0-10]:
```
