# FoxyVPN Desktop v3 (نسخه پیشرفته با پشتیبانی از TUN Mode)

کلاینت دسکتاپ ویندوزی قدرتمند و مدرن برای **پروکسی رایگان و قانونی Firefox VPN موزیلا** (سهمیه ۵۰ گیگابایت ماهانه برای هر اکانت فایرفاکس)، حاصل ادغام معماری مدرن [armanlife/firefox-vpn-client](https://github.com/armanlife/firefox-vpn-client) و قابلیت **TUN Mode اختصاصی ویندوز** با درایور Wintun از پروژه FoxyVPN Desktop.

---

## 🌟 ویژگی‌های کلیدی نسخه ۳ (FoxyVPN Desktop v3)

1. **حالت تونل کل سیستم (Full-System TUN Mode)**:
   - هدایت تمام ترافیک ویندوز (مرورگرها، تلگرام، بازی‌ها، دستورات CMD و نرم‌افزارهای فاقد تنظیمات پروکسی) از لایه شبکه (Network Layer 3) با استفاده از درایور پرسرعت **Wintun** و `hev-socks5-tunnel`.
   - مسیریابی هوشمند مسیرهای دوگانه (`0.0.0.0/1` و `128.0.0.0/1`) و پین کردن خودکار گیت‌وی پیش‌فرض برای جلوگیری از لوپ شدن ترافیک تونل.
2. **سیستم چند اکانتی و چرخش خودکار (Multi-Account Rotation)**:
   - امکان افزودن بی‌نهایت اکانت رایگان فایرفاکس (هر اکانت ۵۰ گیگابایت سهمیه ماهانه).
   - سوئیچ خودکار و آنی به اکانت بعدی به محض اتمام ۵۰ گیگابایت یا لیمیت شدن، بدون قطعی اینترنت.
3. **پشتیبانی از پروتکل‌های HTTP/2 و HTTP/3 (QUIC)**:
   - عبور ترافیک از بستر پرسرعت CDN موزیلا بر پایه شبکه **Fastly**.
   - امکان استفاده از پروتکل جدید HTTP/3 مبتنی بر UDP/QUIC برای پایداری در شرایط اختلالات شدید اینترنت.
4. **مسیریابی هوشمند (Smart Routing برای سایت‌های ایرانی)**:
   - تفکیک خودکار ترافیک داخلی و خارجی بر اساس دیتابیس‌های `geosite` و `geoip`.
   - سایت‌های ایرانی (`.ir` و سرویس‌های داخلی) بدون عبور از پروکسی و به صورت مستقیم با حداکثر سرعت باز می‌شوند تا سهمیه ۵۰ گیگابایت حفظ شود.
5. **پروکسی دوکاره محلی (Dual-Mode Local Proxy)**:
   - پشتیبانی همزمان از پروتکل‌های **SOCKS5** و **HTTP CONNECT** روی یک پورت محلی (`127.0.0.1:10810`).
6. **رابط کاربری مدرن با تم دسکتاپ**:
   - داشبورد زیبا و تاریک با افکت‌های مدرن شیشه‌ای، نمودار پینگ لحظه‌ای، وضعیت سهمیه اکانت‌ها و آیکون System Tray در ویندوز.
   - اجرای مستقیم در حالت پنجره اختصاصی دسکتاپ (App Mode) بدون نیاز به نصب فریم‌ورک‌های سنگین.

## 🚀 نحوه اجرا (Quick Start)

### روش اول: اجرای مستقیم (توصیه‌شده)
فقط کافیست روی فایل **`Run-FoxyVPN.bat`** دابل‌کلیک کنید:
1. فایل به صورت خودکار دسترسی Administrator را درخواست می‌کند (برای فعال‌سازی آداپتور Wintun در حالت TUN).
2. سرویس اصلی و آیکون کنار ساعت ویندوز (Tray) فعال می‌شود.
3. پنجره داشبورد برنامه به‌صورت خودکار باز خواهد شد.

### روش دوم: کامپایل از سورس
اگر می‌خواهید خودتان برنامه را مجدداً بیلد کنید:
```cmd
build.cmd
```
فایل خروجی با نام `foxyvpn-v3.exe` در پوشه `build/` ساخته می‌شود.

## 🛠️ ساختار پوشه `v3`

```
v3/
├── build/
│   └── foxyvpn-v3.exe        # فایل اجرایی کامل ویندوز (شامل Core، Web UI و درایورهای TUN)
├── core/
│   ├── cmd/firefox-vpn-core/ # نقطه ورود برنامه Go
│   ├── internal/
│   │   ├── accounts/         # مدیریت و ذخیره اکانت‌ها و سهمیه‌ها
│   │   ├── fxa/              # ارتباط با پروتکل اکانت فایرفاکس و حل چالش Fastly
│   │   ├── guardian/         # دریافت توکن JWT و بررسی سهمیه
│   │   ├── proxy/            # موتور پروکسی SOCKS5 و HTTP
│   │   ├── routing/          # مسیریابی هوشمند GeoIP و GeoSite
│   │   ├── service/          # وب‌سرور داشبورد و کنترل سرویس‌ها
│   │   │   └── web/          # فایل‌های HTML/CSS/JS رابط کاربری
│   │   └── tun/              # پیاده‌سازی TUN Mode ویندوز (Wintun + hev-socks5)
│   │       └── bin/          # فایل‌های wintun.dll و hev-socks5-tunnel.exe
├── Run-FoxyVPN.bat           # راه‌انداز یک‌کلیکه نسخه ویندوز با دسترسی ادمین
├── build.cmd                 # اسکریپت کامپایل پروژه
└── README.md
```
