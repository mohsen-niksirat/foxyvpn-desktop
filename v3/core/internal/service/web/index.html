FoxyVPN Pro Desktop v3

کلاینت پیشرفته دسکتاپ برای پروتکل امن و پرسرعت Firefox VPN با پشتیبانی کامل از TUN Mode لایه ۳

نرم‌افزار FoxyVPN Desktop v3 یک راهکار قدرتمند، امن و مدرن برای عبور پایدار از محدودیت‌های اینترنت با بهره‌گیری از زیرساخت ابری موزیلا و شبکه توزیع Anycast در شرکت Fastly است. در این نسخه اختصاصی، قابلیت Wintun L3 TUN Mode پیاده‌سازی شده است تا بتوانید بدون نیاز به افزونه یا تنظیم پروکسی، کل سیستم‌عامل ویندوز (شامل تمامی برنامه‌ها، مرورگرها، بازی‌ها و ترمینال) را به شکلی ایمن، تفکیک‌شده و بدون لوپ ترافیک تونل نمایید.

ویژگی‌های کلیدی نسخه ۳

  • TUN Mode لایه ۳ با Wintun: هدایت تمامی اتصالات شبکه ویندوز بدون تداخل یا افت سرعت با معماری مجازی L3.
  • سیستم Multi-Account هوشمند: افزودن چند اکانت فایرفاکس و سوییچ خودکار نامحسوس پس از مصرف سهمیه ۵۰ گیگابایت.
  • پروتکل‌های HTTP/2 و HTTP/3 (QUIC): دور زدن انسدادهای TLS و کاهش شدید پینگ با پکت‌های UDP.
  • تفکیک هوشمند مسیر (Smart Routing): اتصال مستقیم به سایت‌ها، سرویس‌های دولتی و بانکی ایران بدون عبور از VPN.
  • پروکسی لوکال SOCKS5 و HTTP: پشتیبانی همزمان در پورت ۱۰۸۱۰ برای اتصال مستقیم گوشی، تلگرام و نرم‌افزارهای خارجی.

Connecting applications

Any application that can use a SOCKS5 or HTTP proxy can use this one: v2rayN, v2rayNG, NekoBox, a browser, Telegram, and others. Their traffic to any website goes through Mozilla's VPN servers; it is not limited to Mozilla. The same address serves SOCKS5 and HTTP proxy clients.

SOCKS5 address127.0.0.1:10810
Link for v2rayN, v2rayNG, NekoBoxsocks://Og@127.0.0.1:10810
  • v2rayN, v2rayNG, NekoBox: copy the link and import it from the clipboard, or add a SOCKS server with the address above.
  • Another device, such as a phone: set the SOCKS5 listen address to 0.0.0.0:10810 and a SOCKS5 username and password in Settings, then use this computer's network address instead of 127.0.0.1.

Only ports 80, 443, 8080, and 8443

Mozilla's proxy connects to the web ports 80, 443, 8080, and 8443 only. Every other port is refused by Mozilla's server, for example http://203.0.113.5:9898/, SSH (22), mail (25, 465, 587, 993), or DNS (53). This program cannot change that, with one exception: git over SSH to GitHub goes to GitHub's SSH server on port 443 by itself.

  • Serve your own site on one of the four ports (8080 and 8443 are the usual choices).
  • Or let the browser reach that address directly: Firefox, Settings, Network Settings, No proxy for.

TCP only, no UDP

Mozilla's proxy carries TCP connections. UDP does not go through it, so online games, voice and video calls in some applications, and other UDP traffic do not work through this proxy. Browsers are not affected: they use HTTP/2 over TCP when HTTP/3 is not available.

Your country's sites directly (routing)

Optional, in Settings, Routing. The sites and networks of the chosen region (Iran by default; also China, Russia, Afghanistan, Turkey, Indonesia, or Brazil) then go directly through your own internet: faster, not refused for a foreign address, and without using the accounts' quota; everything else still goes through Mozilla. The lists of domains and networks are downloaded by themselves every 10 days. A site reached directly sees your real address.
